# 피드백 기록 (2026-11-19 민국 확정)

글·이미지 작업이 끝날 때마다 그 작업 세션이 파일 하나를 여기에 새로 만듭니다. 규칙 파일은 바로 고치지 않고, 매주 수요일 00:00 '민솜 규칙 주간 최적화'가 이 기록을 모아 한 번에 반영합니다(rules/weekly.md).

## 규칙
① 파일 이름: `YYMMDD-글폴더이름-글.md` 또는 `YYMMDD-글폴더이름-이미지.md`. 작업마다 새 파일이라 다른 대화방과 충돌이 없습니다. 기존 파일은 고치지 않습니다(같은 이름이 있으면 끝에 -2).
② 수요일 작업은 다른 대화방을 읽을 수 없으므로, 판단에 필요한 근거를 이 파일 안에 적습니다: 문제 문장 그대로 인용(40자 이내), 사진 번호·파일명, 열리지 않은 주소, 규칙 번호.
③ 예외(바로 고침): 도구 오류(스크립트가 멈춤), 사실 오류의 원인, 같은 날 같은 실수 2회. 이것만 그 작업에서 바로 규칙·도구를 고치고, 파일에 `상태: 즉시 반영`으로 적습니다.
④ 민국이 "반영해줘"·"피드백한 거 수정해줘"라고 하면 ③ 예외가 아닌 항목은 이 기록에 `민국 요청: 반영 원함`을 붙이는 것으로 끝냅니다(수요일에 우선 반영). 답변은 "수요일 최적화에 넣었습니다" 한 줄입니다.
⑤ 작성 후 작업 브랜치 push → main까지 합칩니다(파일 추가만이라 충돌 없음).

## 양식 (5~10줄)
```
종류: 글 | 이미지
글: (제목)
날짜: YYYY-MM-DD
사용량: 검색 n회, 문서 열기 n개, 헛걸음 n개
상태: 대기
1. [사용량] 무엇이 헛걸음이었나 → 규칙을 어떻게 → 아끼는 양
2. [정확도] 틀린 문장 "…" → 원인 → 규칙 제안(파일 번호)
3. [인사이트] 가장 잘 먹힌 근거·사진 → 다음에도 쓸 방법
4. [민국 지적] 민국이 직접 한 말 그대로
```
