# 민솜 규칙: 매주 월요일 규칙 최적화 + 채팅 동기화 (2026-11-17 민국 지시)

## 목적
민국이 한 주 동안 글 쓰며 준 피드백을 규칙에 녹여 조회수·후킹성이 잘 나오는 방향으로 규칙을 다듬고, 코드 규칙(이 저장소)과 채팅 규칙(채팅 프로젝트 지침)을 같은 내용으로 맞춥니다.

## 기준 원칙 (정본)
- 정본은 이 저장소(CLAUDE.md + rules/)입니다. 채팅 규칙은 정본에서 만든 요약본이며 rules/chat_sync.md가 그 원본입니다.
- 채팅 지침은 claude.ai 설정 화면에서만 바꿀 수 있어 코드 세션이 직접 고칠 수 없습니다. 그래서 매주 chat_sync.md를 새로 만들고, 결과 보고에 "채팅 지침 붙여넣기 블록"을 코드 블록으로 줍니다(민국은 폰으로 그 블록을 채팅 지침에 통째로 붙여 넣으면 동기화 끝).

## 매주 월요일 절차
1. 지난 7일 git log와 변경된 rules/·addressbook.tsv·새 글 폴더(YYMMDD-*)를 읽어 민국의 피드백이 어디에 쌓였는지 파악합니다.
2. 규칙끼리 부딪히는 곳을 찾습니다: (a) 같은 항목의 숫자·기준이 파일마다 다름(예: 글감 개수, 분량, 사진 장수), (b) 예약 작업 프롬프트('민솜 글감 아침 배달')와 rules/topic.md 불일치, (c) 날짜 붙은 ★규칙이 옛 규칙과 겹침, (d) 중복·낡은 문장.
3. 부딪힘 해결 기준(우선순위): ① 최신 날짜 + 민국이 직접 확정한 규칙 > ② CLAUDE.md의 'v2 고정 규칙' > ③ 그 외. 둘 다 민국 확정이라 판단이 안 서면 홈판 조회수·후킹성에 유리한 쪽을 고르고, 근거를 rules/data.md 수치(적중률, 터지는 주제 4가지, 제목 말투)에서 한 줄로 댑니다.
4. 최적화는 같은 뜻을 더 짧고 명확하게(낮은 모델·무료 버전이 글자 그대로 지킬 수 있게) 고치는 것입니다. 민국이 확정한 내용 자체를 뒤집는 것은 하지 않고, 뒤집을 필요가 있으면 결과 보고에 "제안"으로만 올립니다(근거 수치 포함).
5. 개인정보 규칙(블로그 글에 글쓴이 개인 정보 금지), 폰 전용·파일 첨부 요구 금지 등 CLAUDE.md 공통 전제는 건드리지 않습니다.
6. 고친 내용은 rules/ 파일에 반영하고 변경 이유를 커밋 메시지에 적습니다. 현재 세션 브랜치에 커밋·푸시합니다(main 직접 푸시 금지).
7. rules/chat_sync.md를 정본에 맞춰 다시 만듭니다(맨 위 버전 날짜 갱신).
8. 규칙 수정이 필요한지 모를 때 rules/data.md를 먼저 확인합니다. 새 조회수 데이터가 없으면 지난주 글 제목 말투·적중률만 점검합니다.
