# 민솜 규칙: 자동서식 적용해줘 (CLAUDE.md에서 분리, 내용 동일)

## 5. 자동서식 적용해줘 (아이폰 전용, 검증된 흐름이라 구조 변경·자동화 제안 금지)
5-1. 원고를 주며 "자동서식 적용해줘"라고 하면 아래 틀을 그대로 씁니다. 새 서식을 임의로 만들지 않고, 보낸 텍스트를 HTML로 옮기는 변환만 합니다(팩트체크·검색·문장 수정·피드백·검증 메모 금지, 수정 요청이 따로 있을 때만 수정).
5-2. 납품은 두 가지만: ① 확정 제목(text 코드 블록, 원고에 제목이 없으면 추천 제목) ② HTML 한 줄 압축판 코드 블록. 단축어 실행 링크·'다음 순서' 안내·'태그만 복사용' 블록은 넣지 않습니다(태그는 HTML 맨 끝에 포함).
5-3. 틀 v2: body 나눔고딕·padding 22px·본문 16px·line-height 1.9·#111 → 버튼 '원고 전체 선택'(onclick selectArticle(), 18px) → div#article → 서문 문단들 → hr(1px #aaa, margin 30px 0) → '본문 3줄 요약' 제목(가운데·19px·bold) → 초록 박스(background #e5f8cd, 3px solid #000 테두리, padding 18px 20px) 안에 ol/li bold·justify 3줄 → 소제목마다 앞에 hr, 소제목 p(24px bold, margin 0) 뒤에 빈 줄 p → hr → '투자 유의사항' 라벨 p(11px bold) + 본문 p(11px) → 빈 줄 → 태그 p(13px, line-height 1.8) → script selectArticle()(createRange·selectNodeContents(#article)·getSelection). 문단 사이는 <p style="margin:0;"><br></p>, 문단은 <p style="margin:0;">입니다. 초록 박스·'원고 전체 선택' 버튼·script를 빼먹어 재작업한 적이 있습니다.
5-4. 목차는 쓰지 않습니다(옛 원고에 있어도 뺌). 서문이 맨 위이고 3줄 요약 상자는 서문 뒤입니다. 소제목 인용구 서식은 넣지 않습니다(네이버 인용구는 HTML 붙여넣기로 검증 안 됨). '본문 3줄 요약' 가운데 정렬은 HTML로 안 되므로 민국이 직접 합니다(재시도 금지).
5-5. 표: 원고에서 '|'로 시작하는 줄이 연달아 있으면 표 1개로 만듭니다. <table style="border-collapse:collapse;width:100%;font-size:15px;line-height:1.5;">, 칸은 <td style="border:1px solid #999;padding:6px 8px;text-align:center;">, 첫 줄(머리줄)은 font-weight:700;background:#e5f8cd를 추가합니다. '| --- |' 구분줄은 버립니다. 열 3개 이하·칸당 8자 이내(4열이면 5자)를 넘으면 휴대폰에서 좌우 스와이프가 생겨 싫어합니다.
5-6. 형광펜 색: <mark style="background:색;font-weight:700;"> — 노랑 #fff8b2, 초록 #c2f4db, 파랑 #b0f1ff, 빨강 #ffcdc0.
5-7. 형광펜 기준(중요도 노랑 < 초록·파랑 < 빨강, 문장 단위): 빨강 = 소제목마다 가장 중요한 문장 1개(최대 2개), 서문에도 1개, 빨강 있는 문단엔 노랑 없음 / 노랑 = 문단마다 핵심 문장 1개(없으면 비움) / 파랑·초록 = 보조 문장, 소제목(서문 포함)당 합쳐서 최대 2개, 같은 문단에 같은 색 두 번 금지, 파랑 있는 문단에 더 필요하면 초록. 많이 칠하면 중구난방이라 싫어하므로 한 문단(2~3문장)에 색 하나 위주로 칠합니다.
  초록 문장 기준: "첫째·둘째" 식 나열 문장은 무조건 초록(반복 허용) / 여러 대상(예: 서울대·아주대·고려대 병원)을 나란히 비교하는 글은 대상별 비교 문장도 초록 / 문단 첫 문장이 짧게 끝나며 화제를 전환하면("법이 정한 순서는 다음과 같습니다") 그 첫 문장을 초록 / 초록을 칠한 문단에는 파랑 보조 문장도 함께 / 너무 긴 문장은 칠하지 않습니다.
5-8. 영문 'AMAT'는 HTML 소스 안에서 &#65;&#77;&#65;&#84; 코드 표기로 씁니다(제목 줄·화면 표시는 그대로, 태그 #AMAT도 코드 표기). 단축어 '변환 오류(리치 텍스트를 URL로 변환할 수 없음)'의 해결법입니다. LH·ASM·ASML·SK·KTX는 그대로 두고, 새 영문 약어가 든 글이 또 안 되면 그 약어부터 같은 방식으로 의심합니다. 모든 약어를 일괄 코드 표기하지는 않습니다.
5-9. 남사터널 글(2026-10-21)은 민국이 직접 수정해 새 형광펜 규칙으로 다시 칠하지 않습니다.
